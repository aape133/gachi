gachi

ASIO 오디오 장치가 필요해요

gachi는 지연을 줄이려고 ASIO로만 소리를 주고받아요. 이 PC에서는 ASIO 드라이버를 찾지 못했어요.

오디오 인터페이스 제조사 홈페이지에서 ASIO 드라이버를 설치한 뒤 다시 확인해 주세요. DAW와 함께 쓴다면 설정 → 오디오에서 VST 연결을 고르면 앱에는 ASIO 장치가 없어도 돼요.

    입력 채널

    소리를 내 보면 신호가 들어오는 채널에 막대가 올라와요. ‘마이크 + 스테레오’로 마이크와 루프백(PC 소리)을 함께 보낼 수 있어요. 테스트 톤에 막대가 올라오는 루프백은 고르지 마세요: 이 앱의 출력(상대 소리)이 다시 들어오는 채널이라, 상대에게 자기 소리가 되돌아가요.

    메트로놈 음량

    클릭 소리는 나에게만 들리고 상대에게는 보내지 않아요.

    테스트

    방장일 때, 같은 공유기(Wi-Fi·유선)에 있는 사람의 첫 화면에 방이 떠요. 코드가 켜져 있을 때만 보이고, 다른 네트워크에는 보이지 않아요.

    음질

    고급 설정
    패킷 크기

    자동은 장치 버퍼 크기에 맞춰 보내요(64보다 크면 똑같이 나눠서). 직접 고를 때는 작을수록 빠르지만 업로드 패킷 수가 늘고, 장치 버퍼보다 작게 해도 더 빨라지지는 않아요.

    지터 버퍼

    연결이 가끔 멈칫할 때 어느 쪽을 택할지예요. ‘빠르게’는 버퍼를 작게 두고 멈칫한 순간을 소리 이어 붙이기로 넘겨요(지연 ↓, 짧은 끊김 ↑). ‘안정’은 버퍼를 키워 막아요(지연 ↑, 끊김 ↓). 고른 연결에서는 셋이 같아요.

    자동은 상대별로 끊김 없는 최소 크기를 계속 맞춰요. 상대 카드의 지연 숫자를 눌러 개별 조정할 수도 있어요.

    연결 상태

    화면을 그릴 때 그래픽카드를 써요. 화면이 깜빡이거나 깨지면 꺼 보세요. 소리와 암호화(AES-256)에는 영향이 없어요. 앱을 다시 시작하면 적용돼요.

    다시 시작해야 적용돼요.

    프로그램을 켤 때 GitHub에 새 버전이 나왔는지 한 번 물어봐요. 새 버전이 있으면 첫 화면에 알려 주기만 하고, 스스로 내려받거나 설치하지 않아요. 물어보는 순간 GitHub가 내 인터넷 주소(IP)를 볼 수 있어요.

    문제를 조사할 때만 켜세요. 꺼 두면 일어난 일만 짧게 남기고, 켜면 연결 상태를 2초마다 자세히 남겨요. 로그는 이 PC에만 저장되고(최근 5개) 어디로도 보내지 않아요. 닉네임·채팅·비밀번호는 남지 않아요.

    개인정보

    소리와 채팅은 방에 있는 사람들끼리 직접(P2P) 암호화해서 주고받고, 서버를 거치지 않아요. 연결 서버는 방을 소개만 하고, 누가 접속했는지(인터넷 주소 포함)를 저장하지 않아요. 다만 접속하는 순간에는 연결 서버와 그 운영자, 서버를 호스팅하는 Cloudflare가 인터넷 주소(IP)를 볼 수 있어요. 또 직접 연결이라 같은 방 사람들끼리는 서로의 IP를 알 수 있어요.
